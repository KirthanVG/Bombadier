# Bombadier!

This is a fun little website coded with Claude in my free time. It simulates the damage of explosions on a map. It uses real-world data and heatmaps to form a best estimate of the damage.

## The hard truth

A.I. is a highly controversial topic in many sectors. I am not here to give an opinion, but to suggest a way of working with A.I. to create quality builds without offloading all your work to it. While A.I. can write code, it is still up to the human to review, test and give direction to the project. You will also have to look out for A.I.'s blind spots, such as user privacy and cybersecurity.

## Coding for fun

Not every project with A.I. has to be about some money-printing machine or quant trading bot. As I believe is the case for many others, my love for coding started because it let me create and build wonderful things, limited only by my creativity. A.I. should assist with this.
